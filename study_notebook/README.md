# AVA // THE MACHINE — Study Notebook

Drop any reference file into `references/` and Ava will index it in RAM:

| Folder | Purpose |
| :--- | :--- |
| `references/` | Your study materials: PDFs, Markdown notes, TXT cheat-sheets |
| `takeaways/` | Auto-generated session summaries exported by Ava |
| `quizzes/` | Auto-generated quiz banks from your study materials |

> Files are read into RAM only. Ava never modifies your references.
